# HANCOCK attention explorer

Static research gallery of the existing HANCOCK cases, H&E thumbnails, normalized attention maps, patch crops, density figures and AI morphology comments. The original page layout is retained. Only public presentation files are included; training code, checkpoints, feature arrays, server paths and private run receipts are excluded.

## Data attribution

Source: **HANCOCK — Multimodal Head and Neck Cancer Dataset**, HANCOCK research team, Friedrich-Alexander-Universität Erlangen-Nürnberg.

- Dataset: https://doi.org/10.48742/fau.b9f7-hd44
- Official repository: https://data.fau.de/public/24/87/322108724/
- Author download information: https://hancock.research.fau.eu/download
- Dataset license: Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/).

Images on this website are derived thumbnails and resized patch crops; colored attention overlays and density figures were generated by the research pipeline. AI comments and attention are research visualizations, not clinical diagnoses. Original dataset authors do not endorse these analyses.
